# Docs Structure

This folder is organized around four research-building blocks.

## 1. Data

`docs/data/` keeps source definitions, sample funnels, and empirical run logs.

- `docs/data/00_data_sources_and_funnel.md`
- `docs/data/empirical_runs/`

## 2. Theory

`docs/theory/` keeps the economic logic transferred from Qian et al. to the China setting.

- `docs/theory/00_theory_mapping.md`

## 3. Research Question

`docs/research_question/` keeps the replication scope and what this project does not claim.

- `docs/research_question/00_research_question.md`

## 4. Identification

`docs/identification/` keeps event-study design choices, known threats, and acceptance criteria.

- `docs/identification/00_identification_design.md`
